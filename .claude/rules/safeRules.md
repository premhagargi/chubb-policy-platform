# Safety rules

Things `.claude/settings.json` can't express as a deny-pattern, or that need the
*reason* spelled out so a future edit doesn't quietly undo them.

## Secrets

- Never commit an API key. `backend/.env` holds `CEREBRAS_API_KEY` and is
  git-ignored; `.env.example` documents the variable names only, with no real
  values. If you ever see a real key in a diff, stop and flag it — don't commit
  around it.
- `openapi/openapi.yaml` is generated by `backend/scripts/export_openapi.py` — it
  says "do not edit by hand" in its own docstring. Regenerate it, never hand-patch
  it, even for a one-line fix.

## API surface

- Never delete the portfolio-brief AI endpoint. It's live and tested but has no
  dashboard card (removed from the UI) — it is still part of the documented
  contract. "Unused in the UI" is not a reason to remove it.
- Every route lives under `/api/v1` via `api/v1/router.py`. Don't mount a route
  anywhere else, even temporarily for testing.

## AI grounding

- AI answers must be grounded in live data read through the same cached query
  service the REST endpoints use (`AiService`). Never let the model answer a
  factual question about policies from its own memory — if the data path isn't
  there, the feature doesn't ship yet.
- Model output is untrusted text. It renders only through Angular property
  bindings (`markdown-text.component.ts`), never `innerHTML`. Don't introduce a
  Markdown renderer that emits raw HTML.
- Parse model output defensively — a model will wrap JSON in a code fence or add
  a sentence despite instructions. Extract and range-check rather than trusting
  the raw response (see `_parse_risk_json` for the pattern).

## Conventions that look like cleanup but aren't

- Don't "simplify" `Money` back to a plain `Decimal`. Pydantic renders `Decimal`
  as a JSON string by default, which silently breaks arithmetic in the UI —
  `Money` exists specifically to keep it a JSON number.
- Don't move filter bounds into `Query(ge=..., le=...)`. FastAPI stops at the
  first validation failure; `parse_policy_filter` intentionally accumulates every
  error before raising once.
- Don't use `.name` or `str()` to build a wire value for an enum. `"A&H"` and
  `"Hong Kong"` aren't valid Python identifiers, so `WireEnum.value` is the only
  source of truth for both the DB and the JSON wire format.
- Any new mutation must call cache invalidation (`invalidate_all()` via
  `CacheInvalidatingPolicyCommandService`). A mutation that skips it serves stale
  reads for the rest of the TTL — this is the exact failure mode the generation
  counter in `core/cache.py` exists to prevent.

## Destructive actions

- Treat `git push --force`, `git reset --hard`, `git clean -f`, and `rm -rf`
  the same as production changes even in this POC — confirm with the user first.
  `.claude/settings.json` denies the obvious patterns, but a differently-shaped
  command can still slip through; the rule is the intent, not just the regex.
